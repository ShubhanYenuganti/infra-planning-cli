## Skipped paths (press warnings)

Press skipped 7 of 12 paths because it could not derive resource names from GCP's
`{parent}` / `{name}` path parameters (GCP uses hierarchical parent paths, not REST
resource names). Only paths that press could parse into commands were generated.

Skipped: `/v2/{name}`, `/v2/{name}/operations`, `/v2/{parent}/executions`,
`/v2/{parent}/jobs`, `/v2/{parent}/revisions`, `/v2/{parent}/services`,
`/v2/{parent}/tasks`.

This is a known GCP/press mismatch. The full Cloud Run API surface requires manual
patches or an upstream press fix for GCP-style path parameters.
