# cloud-run-admin-pp-cli — Agent Guide

A focused CLI for Google Cloud Run Admin API v2. Manages jobs, services, revisions,
executions, and tasks. Generated by CLI Printing Press v1.3.2 from the OpenAPI 3.0
spec at apis.guru (googleapis.com/run/v2).

## When to use this CLI

- List, get, create, or delete Cloud Run services and jobs in a GCP project
- Manage IAM policies on Cloud Run resources
- Inspect revisions, executions, and tasks for debugging failed runs
- Export resource state to JSON for audit or diffing

## Authentication

Set `CLOUD_RUN_ADMIN_TOKEN` (Bearer token) or configure `~/.config/cloud-run-admin-pp-cli/config.yaml`.
Run `cloud-run-admin-pp-cli doctor` to verify auth and API connectivity.

## Key subcommands

| Subcommand | Purpose |
|---|---|
| `api` | Raw API passthrough for any Cloud Run endpoint |
| `auth` | Manage authentication credentials |
| `doctor` | Health-check config, auth, and API reachability |
| `export` | Export resources to JSON |
| `import` | Import resources from JSON |
| `resource-get-iam-policy` | Get IAM policy for a Cloud Run resource |
| `resource-set-iam-policy` | Set IAM policy for a Cloud Run resource |
| `sync` | Sync resources to local SQLite cache (v1.1) |
| `search` | Full-text search over synced resources (v1.1) |
| `sql` | Raw SQL against local cache (v1.1) |

## Agent-friendly usage

Always pass `--agent` for minimal, parseable output:

```
cloud-run-admin-pp-cli --agent resource-get-iam-policy --name projects/my-proj/locations/us-central1/services/my-svc
```

## Local cache

Data stored at `~/.infra-press/cloud-run-admin-pp-cli.db` (SQLite/FTS5).
`sync` populates it; `search` and `sql` query it offline.

## Known gaps (v1.0)

- 7 GCP hierarchical paths skipped by press (parent-based routes require manual patches)
- `sync`/`search`/`sql` return "not yet implemented" — full SQLite backend lands in v1.1
