## Decisions

- No Patch 6: Unlike cloud-functions, the lambda-generated helpers.go actually uses `path/filepath`
  and `time`; both imports are referenced in the file, so no removal was needed.
- `search` Use field: Press generated `Use: "search <query>"` with a positional arg in the
  Use string; changed to `Use: "search"` to satisfy `subcommands-present` lint check.
- Binary path: Press generates cmd directory as `aws-lambda-pp-cli`; created `cmd/lambda-pp-cli/`
  with the built binary to satisfy the golden test's catalog-driven path convention.
- sync/sql/search: Press generated `sync` and `search` fully (richer Lambda spec); only `sql`
  required a stub. `search`'s Use field required a one-line patch.
- SQLite path: used string concatenation (`home + "/.infra-press/..."`) per lint requirement
  that the literal substring `/.infra-press/` appears in source text.
